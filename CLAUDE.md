## Project Overview

Personal portfolio website for an AI/ML engineer deployed on GitHub Pages. The site features a beer rating system with Gradio UI for data entry, auto-generated JavaScript from JSONL data, and SVG radar chart visualizations.

**Live Site:** https://xinzhang-ops.github.io/personal_page/

## Development Commands

### Build Commands
```bash
# Build main site assets (CSS/JS optimization)
npm run build

# Build beer gallery from data/beer.jsonl
npm run build-beer

# Build everything (safest option)
npm run build-all

# Add new beer via Gradio UI
python scripts/add_beer.py
```

### Testing
```bash
# Run all tests
npm test

# Run tests in watch mode
npm run test:watch

# Run property-based tests only
npm run test:pbt

# Performance testing
npm run perf

# Build + performance test
npm run optimize

# Verify deployment readiness
npm run verify-deployment

# Full pre-deployment check
npm run deploy-check
```

## Architecture

### Build System & Data Flow

**Main Site:** Files are edited directly but referenced as source
- Edit: `index.html`, `css/main.css`, `js/main.js`
- Run: `npm run build` (validates assets, no actual minification currently)
- Site loads from source files

**Beer Rating System:** Auto-generated from data
```
data/beer.jsonl → scripts/build-beer.cjs → js/beer.js → pages/beer.html
```
- `data/beer.jsonl`: JSONL format (one JSON object per line), source of truth
- `scripts/build-beer.cjs`: Reads JSONL, generates complete `beer.js` with embedded data and rendering logic
- `js/beer.js`: AUTO-GENERATED file, do not edit manually
- `pages/beer.html`: Loads `beer.js` to display beer gallery

After adding beers via Gradio UI or editing `beer.jsonl`, you MUST run `npm run build-beer` to regenerate `beer.js`.

### Module Organization

**Content Management:**
- Projects: Defined in `js/main.js` → `projects` array
- Writing: Defined in `js/main.js` → `writings` array
- To add content: Edit these arrays, then run `npm run build`

**AI Assistant Widget:**
Modular architecture split across multiple files:
- `js/ai-assistant-constants.js`: Configuration (icons, dimensions, messages, timing, context info)
- `js/ai-assistant-config.js`: Server URL configuration (local/ngrok/production)
- `js/ai-assistant-storage.js`: LocalStorage utilities
- `js/ai-assistant-positioning.js`: Position calculations
- `js/ai-assistant-templates.js`: HTML templates
- `js/ai-assistant-dom-utils.js`: DOM helpers
- `js/ai-assistant.js`: Main logic
- See `js/AI_ASSISTANT_README.md` for customization guide

**Internationalization (i18n):**
- `js/i18n/`: Translation files for supported languages
- `js/i18n.js`: i18n implementation

### Beer Rating System

**6 Scoring Aspects (1-10 scale):**
1. 麦芽香 (Maltiness)
2. 颜色深浅 (Color Depth)
3. 清澈度 (Clarity)
4. 苦度 (Bitterness)
5. 其他香味 (Other Aromas)
6. 综合 (Overall)

**Image Processing:**
- Gradio UI auto-resizes to 400x400px PNG
- Saves to `assets/images/beers/`
- Uses timestamp-based naming
- Manual images: Use `../` prefix in JSONL paths (because beer.html is in pages/ directory)

**Visualization:**
- Pure SVG radar charts (no external dependencies like Chart.js)
- No lazy loading for images (causes grey box issues with dynamically created images)
- Sort by any score aspect or date

## Key Implementation Patterns

### Path References
- Images in `beer.jsonl` must use `../` prefix: `"imageUrl": "../assets/images/beers/filename.png"`
- This is because `pages/beer.html` loads from `pages/` directory

### Auto-Generated Files
Never edit these files directly:
- `js/beer.js` - Generated by `scripts/build-beer.cjs`

### Data Format
```json
{
  "name": "Beer Name",
  "style": "IPA",
  "abv": 6.5,
  "notes": "Tasting notes",
  "scores": {
    "maltiness": 5,
    "colorDepth": 6,
    "clarity": 7,
    "bitterness": 8,
    "otherAromas": 7,
    "overall": 7.5
  },
  "imageUrl": "../assets/images/beers/beer-name-timestamp.png",
  "date": "2024-01-15"
}
```

### Customize AI Assistant
Edit `js/ai-assistant-constants.js`:
- Icons: `AI_CONSTANTS.ICONS`
- Dimensions: `AI_CONSTANTS.DIMENSIONS`
- User context: `AI_CONSTANTS.CONTEXT_INFO` (name, role, expertise, etc.)
- Error messages: `AI_CONSTANTS.MESSAGES`

See `js/AI_ASSISTANT_README.md` for detailed customization guide.

## Deployment

The site deploys to GitHub Pages from the `main` branch:

```bash
npm run build-all           # Build everything
git add .
git commit -m "message"
git push                    # GitHub Pages auto-deploys
```

Deployment may take a few minutes to reflect.

## Important Notes

- **Beer images**: Do not use lazy loading (interferes with dynamic image creation)
- **Build requirement**: Always run `npm run build-beer` after modifying `data/beer.jsonl`
- **Image paths**: Beer images must use `../` prefix in JSONL because beer.html is in pages/
- **Auto-generated**: Never edit `js/beer.js` manually
- **Content arrays**: Projects and writings are defined in `js/main.js` arrays
